Components

A component is defined once and used as a tag, in markup or from JavaScript.

{get.heading}

{get.content}

 The template is declared in a single place. Each attribute on the tag is available inside the template.

<wraps>
  <wrap tag="note-card">
    <div class="card {get.tone}">
      <h3>{get.heading}</h3>
      <p>{get.content}</p>
    </div>
  </wrap>
</wraps>

<div class="row"><button @AddCard type="button">Add card from JavaScript</button></div>
<div @Board></div>

<script>
  Anchor.ready.then(() => {
    let count = 0;
    Anchor.elements.AddCard.addEventListener("click", () => {
      count++;
      const card = Anchor.createWrap("note-card", null, "Created with Anchor.createWrap.", {
        tone: "ok",
        heading: "Card " + count
      });
      Anchor.mount(card, "@Board", "append");
    });
  });
</script>

Demonstrates: <wraps> templates, {get.attr} and {get.content}, Anchor.ready, Anchor.createWrap, Anchor.mount.
